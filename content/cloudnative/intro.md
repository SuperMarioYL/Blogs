# Cloud Native

欢迎来到云原生技术专区！这里记录了我在 Kubernetes、容器化和云原生领域的实践经验。

## 主要内容

### ☸️ Kubernetes

- Kubernetes 核心概念与架构
- 生产环境最佳实践
- 多租户架构设计
- 高可用集群搭建
- 资源管理与调度优化

### 🐳 Docker & 容器化

- Docker 基础与进阶
- 容器镜像优化
- 多阶段构建实践
- 容器安全最佳实践
- Docker Compose 应用编排

### ☁️ 云原生技术

- Service Mesh (Istio, Linkerd)
- Serverless 架构
- 云原生存储方案
- 可观测性 (Prometheus, Grafana)
- GitOps 实践 (ArgoCD, Flux)

### 🛠️ DevOps 实践

- CI/CD 流水线设计
- 基础设施即代码 (Terraform, Ansible)
- 自动化运维
- 监控告警体系
- 日志收集与分析

## 学习路线

1. **容器基础**: 掌握 Docker 和容器化技术
2. **Kubernetes**: 学习 K8s 核心概念和操作
3. **云原生生态**: 了解 CNCF 生态系统
4. **运维实践**: 构建完整的 DevOps 流程

## 技术栈

- **容器编排**: Kubernetes, Docker Swarm
- **容器运行时**: Docker, containerd, CRI-O
- **服务网格**: Istio, Linkerd
- **可观测性**: Prometheus, Grafana, ELK
- **CI/CD**: Jenkins, GitLab CI, GitHub Actions, ArgoCD
- **基础设施**: Terraform, Ansible, Helm
